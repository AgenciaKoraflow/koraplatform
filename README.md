# KoraPlatform

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desenvolvimento local

Pré-requisito: Node.js & npm — [instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# Instalar dependências
npm i

# Iniciar servidor de desenvolvimento
npm run dev
```

## Build

```sh
npm run build
```
